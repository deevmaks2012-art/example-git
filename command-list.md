# Установка GIT

Скачать git можно по ссылке: https://git-scm.com/

после установки необходимо указать конфигурационные переменные user.name и  user.email
без них git не даст создавать коммиты.

## Конфигурация

Конфигурация в GIT может задаваться в 3 областях действия (для всей системы целиком --global, для пользователя --user, для репозитория --local)

Посмотреть текущие настройки можно командой:
    git config --list

Задать конфигурацию можно командой:
    git config --global user.name "Deev Maksim"
    git config --global user.email "deev@mail.com"

## Создание репозитория

    git init

## Статус репозитория

    git status

## Добавление файла в индекс

    git add *путь до файла*
    git add .

    git rm *путь до файла*
