# Установка GIT

Скачать git можно по ссылке: https://git-scm.com/

после установки необходимо указать конфигурационные переменные user.name и  user.email
без них git не даст создавать коммиты.

## Конфигурация

Конфигурация в GIT может задаваться в 3 областях действия (для всей системы целиком --global, для пользователя --user, для репозитория --local)

Посмотреть текущие настройки можно командой:
    git config --list

Задать конфигурацию можно командой:
    git config --global user.name "Deev Maksim"
    git config --global user.email "deev@mail.com"

## Создание репозитория

    git init

## Статус репозитория

    git status

## Добавление файла в индекс

    git add *путь до файла*
    git add .

    git rm *путь до файла*

## Создание коммита

    git commit -m "Текст сообщения для коммита"

## Просмотр информации о коммитах

Список коммитов:
    git log

Подробная информация о коммите:
    git show *хеш коммита*

## Перемещение указателя HEAD (переключение веток)

    git checkout *название ветки*

    git checkout *хеш коммита*

## Создание новой ветки

    git checkout -b *название ветки*

## Список доступных веток

    git branch

## Слияние веток

Чтобы влить изменения другой ветки в текущую
    git merge *название ветки*

## Добавление ссылки на удаленный репозиторий

    git remote add origin *ссылка*

Чтобы отправить изменения из локального репозитория в удаленный
    git push origin *ветка*

Чтобы получить изменения из удаленного репозитория
    git pull origin *ветка*

## Клонирование удаленного репозитория

    git clone *ссылка на репо*
